Privacy Policy – SVC Repair System

Last updated: 17 November 2026

Who we are

SVC Repair System is an internal web application used by Al-Maidan service centres to manage device repairs, spare-parts inventory, transfers and invoices. It is used only by authorised staff of the company.

What data the app accesses

When a staff member signs in with Google, the app asks for access to Google Drive. It uses this access only to read and write the company's own service data files (JSON files) inside the company's Drive folder. The app does not read, change or delete any other files in the user's Drive.

What data is stored

Repair jobs, customer names and phone numbers entered by staff, device details, spare-parts inventory, prices, transfers, invoices and an activity log. This data is stored in the company's Google Drive and in the browser's local storage on the staff member's device.

Sharing

We do not sell, rent or share any data with third parties. Data is not used for advertising. Google user data is used only to provide the features of this app.

Security

Access is limited to authorised accounts. Passwords inside the app are stored as salted hashes, never in plain text.

Removing access

Any user can remove the app's access at any time from Google Account → Security → Third-party access. To request deletion of data, contact the company administrator.

Use of Google user data

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
